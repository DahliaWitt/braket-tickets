# Braket Tickets Frontend

Angular app package for the Braket Tickets workspace.

Use the root workspace commands from the repository root:

- `pnpm dev` for local development.
- `pnpm test:frontend` for frontend unit tests.
- `pnpm typecheck:frontend` for frontend typechecking.
- `pnpm test:e2e:serve` and `pnpm test:e2e:run --grep "name"` for iterative E2E runs.

See the root `README.md`, `AGENTS.md`, and `docs/` for current project guidance.
