# Managing Events

## Creating an Event

1. Navigate to your Community Admin dashboard → Events tab
2. Click "New Event"
3. Fill in the event details: title, date, location, description
4. Configure ticket tiers with pricing and capacity
5. Set the event visibility (private to your community, or public)
6. Save and publish

## Event Visibility

| Visibility | Who can discover or view it | Who can purchase tickets |
| --- | --- | --- |
| **Private** | Authenticated, vetted members only | Authenticated, vetted members only |
| **Public (viewable)** | Anyone, including signed-out visitors | Vetted members only |
| **Public** | Anyone, including signed-out visitors | Anyone; vetting is not required |

Draft and cancelled events are hidden from public event pages. Community admins can still manage those events from the admin dashboard.

## Managing Check-in

Use the Scanner feature to check in guests at the door. Scan the QR code on each guest's ticket — the system verifies in real-time.
