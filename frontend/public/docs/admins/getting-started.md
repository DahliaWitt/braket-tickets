# Getting Started as a Community Admin

## Your Dashboard

The Community Admin dashboard is your home base. From here you can manage vetting applications, create events, and configure your community settings.

## Key Sections

- **Pending** — Review and approve/deny vetting applications
- **Members** — See all vetted members of your community
- **Events** — Create and manage your events
- **Settings** — Configure your community name, email, and vetting questions
- **Magic Links** — Create invite links that auto-vet recipients
- **Audit Log** — Track all admin actions for accountability
