# Getting started as a community admin

This assumes you've already been added as an admin. If not, ask an existing admin to invite you from Settings → Team.

## Your dashboard

The Community Admin dashboard has eight tabs:

| Tab                | What it's for                                                                          |
| ------------------ | -------------------------------------------------------------------------------------- |
| **Pending Apps**   | Review incoming vetting applications — approve or deny each one                        |
| **App History**    | Look back at past application decisions                                                |
| **Members**        | See everyone who's been vetted into your community                                     |
| **Events**         | Create and manage your events                                                          |
| **Magic Links**    | Generate invite links that automatically vet the recipient                             |
| **Audit Log**      | Track admin actions for accountability                                                 |
| **Shared Vetting** | Manage trust links with other communities                                              |
| **Settings**       | Configure your community profile, vetting questions, team, payments, and notifications |

## First steps

If you're setting up a brand new community, here's a reasonable order:

1. Head to **Settings** and fill out your community profile — name, slug, description, logo. Toggle on directory listing if you want to show up in the public community directory.
2. Scroll down to **Vetting Questions** (still in Settings). These are what applicants fill out when they want to join. Think about what you actually need to know to make a decision.
3. Selling paid tickets? Connect Stripe from the **Payments** section in Settings. See [Set up Stripe](./stripe-setup.md).
4. Go to the **Events** tab and create your first event. Fill in the details, set up ticket tiers, and publish when you're ready. See [Managing events](./managing-events.md).
5. Invite co-admins from **Settings → Team** so you're not doing everything alone.

## Reviewing applications

When someone applies, their application lands in Pending Apps. Read their answers, then approve or deny. If you deny someone, include a reason — silence feels worse than a clear "no."

Processed applications move to App History. See [Vetting applications](./vetting-applications.md) for the full workflow.
