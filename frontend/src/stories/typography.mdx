# Typography

## Font Families

| Role | Font | CSS Class | Usage |
|---|---|---|---|
| Display / Headings | Syne | `font-display` | Page titles, hero text |
| Body | Inter | `font-sans` | Paragraphs, descriptions |
| Labels / Code | Space Mono | `font-mono` | Buttons, badges, data labels |

## The Mono Signature

The brand's DNA is: **`font-mono uppercase tracking-widest text-2xs`**

This pattern appears on 400+ elements across the app. It is what makes the UI feel like Pulp instead of generic SaaS. Every new UI element should consider whether its labels should use this pattern.

Examples of where it appears:
- Badge text (`z-badge`)
- Navigation items
- Section headers and metadata labels
- Status indicators
- Form field labels
