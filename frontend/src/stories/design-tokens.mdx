# Color Palette — Pulp

Colors are defined as HSL custom properties in `styles.css` `@theme` blocks.
The live palette is in the **Colors > Palette** story. Treat that story as the canonical token reference because it reads actual computed values from the DOM instead of duplicating a static list here.

## Token Relationships

The color system has three layers:

1. Base semantic tokens such as background, foreground, primary, secondary, accent, muted, border, input, ring, card, popover, and destructive.
2. Tailwind-facing aliases such as success, warning, info, and their foreground pairs.
3. Component usage rules that map those tokens onto product states: primary actions, secondary actions, warnings, errors, passive surfaces, and focus affordances.

Keep this page focused on relationships and rationale. When adding or renaming tokens, update the live **Colors > Palette** story so the docs remain grounded in computed CSS rather than a hand-maintained table.

## Border Radius

| Token         | Value                           |
| ------------- | ------------------------------- |
| `--radius`    | 0.25rem (4px)                   |
| `--radius-md` | calc(var(--radius) - 2px) = 2px |
| `--radius-sm` | 0 (sharp)                       |

Note: mixed radius is intentional — some elements sharp (0), some slightly softened (4px). Uniform rounding is an anti-pattern for this brand.
