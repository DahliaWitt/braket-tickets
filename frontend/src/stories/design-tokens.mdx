# Color Palette — Pulp

Colors are defined as HSL custom properties in `styles.css` `@theme` blocks.
The live palette is in the **Colors > Palette** story — it reads actual computed values from the DOM.

## Token Relationships

| Token | Derives From | Usage |
|---|---|---|
| `--primary` | — | Deep Plum/Wine. CTAs, active states, brand accent |
| `--primary-foreground` | `--primary` | Text on primary backgrounds |
| `--secondary` | — | Violet. Secondary actions, hover accents |
| `--accent` | — | Burnt Amber. Warm highlights, emphasis |
| `--ring` | `--primary` | Focus ring color (2px solid + 2px offset) |
| `--border` | `--muted` | Same hue as muted, used for card/input borders |
| `--destructive` | — | Delete actions, error states |

## Border Radius

| Token | Value |
|---|---|
| `--radius` | 0.25rem (4px) |
| `--radius-md` | calc(var(--radius) - 2px) = 2px |
| `--radius-sm` | 0 (sharp) |

Note: mixed radius is intentional — some elements sharp (0), some slightly softened (4px). Uniform rounding is an anti-pattern for this brand.
